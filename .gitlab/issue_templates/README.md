# Issue Templates

This project uses structured issue templates to enforce disciplined, safety-aware development.

Issues are used to:
- Define scope before implementation
- Document architectural intent
- Track safety-impacting changes
- Maintain traceability between design and code

Each issue should result in:
- A dedicated feature branch
- A merge request
- CI validation
- Automatic closure via commit reference

This workflow ensures motion-control logic remains deterministic, testable, and reviewable.
